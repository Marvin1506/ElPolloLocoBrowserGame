# El Pollo Loco – 2D Browser Game

El Pollo Loco is a browser-based 2D jump-and-run game built with HTML, CSS, JavaScript, and HTML5 Canvas.  
The project focuses on object-oriented programming, game mechanics, animations, collision detection, and structured JavaScript architecture.

The player controls a character through a side-scrolling world, collects items, avoids or defeats enemies, and faces a final boss. The game was developed to deepen practical knowledge of JavaScript classes, canvas rendering, game loops, and interactive browser-based gameplay.

## Features

- 2D side-scrolling jump-and-run gameplay
- HTML5 Canvas rendering
- Object-oriented JavaScript architecture
- Character movement and jumping mechanics
- Enemy movement and collision detection
- Collectible items coming soon
- Health and status bars coming soon
- Throwable objects coming soon
- Final boss encounter coming soon
- Sprite-based animations coming soon
- Keyboard controls
- Sound and game interaction logic
